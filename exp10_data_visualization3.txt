# theory

# what is data visualization?

data visualization is graphical representation of data using:

* graphs
* charts
* plots

it helps in:

* understanding data
* finding trends
* identifying outliers
* comparing distributions

---

# histogram

histogram represents frequency distribution of numerical data.

used for:

* understanding spread of data
* identifying skewness
* checking data concentration

---

# boxplot

boxplot displays:

* minimum value
* maximum value
* median
* quartiles
* outliers

outliers appear as points outside whiskers.

---

# pairplot

pairplot compares relationships among multiple variables.

used for:

* feature comparison
* identifying class separation

---

# nominal data

nominal variables contain category names without numerical meaning.

example:

* flower species

---

# numeric data

numeric variables contain measurable numerical values.

examples:

* height
* age
* petal length
